# TechFest Control Center

Proyecto base para el laboratorio virtual de la Semana 2 de Tecnologías Web 1.

## Contexto

El proyecto representa una pequeña herramienta de consola para consultar y procesar información de talleres de un evento tecnológico universitario.

## Conceptos presentes

- Node.js.
- módulos ES.
- `package.json`.
- scripts de npm.
- `dependencies` y `devDependencies`.
- variables de entorno.
- `process.env`.
- operaciones asíncronas.
- investigación de paquetes en npm.
- separación básica de responsabilidades.

## Requisitos

- Node.js 24 LTS o superior.
- npm.

## Instalación y ejecución

```bash
npm install
npm run start
```


Durante la practica se realizarán modificaciones sobre este proyecto.
